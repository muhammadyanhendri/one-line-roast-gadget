Entry for the [make.fun](https://make.fun/c/u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610) bounty **"One-Line Roast: The Gadget You Use Every Day"**.

`main.ts` (Node 22, stdlib only, no network) writes a single original roast line
of at most 200 characters to `/output/entry.txt`:

> My smartwatch throws me a party for standing up, then files a complaint when I sit back down thirty seconds later.

Run it with `node main.ts` (or set `MAKEFUN_OUTPUT_DIR` to choose the output folder).
